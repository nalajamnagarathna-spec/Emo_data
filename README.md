# Emp_data
# Employee Data Cleaning & Analysis Using Python (Pandas)

## Project Description

This project demonstrates an end-to-end employee data cleaning and analysis workflow using **Python**, **Pandas**, and **Matplotlib**. The dataset contains employee information such as Employee ID, Name, Gender, Department, Salary, Joining Date, and Email. The objective was to clean inconsistent data, identify data quality issues, and generate meaningful business insights to support better workforce management and decision-making.

## Project Highlights

* Imported and explored the employee dataset using Pandas.
* Cleaned missing, invalid, and inconsistent data.
* Replaced placeholder values such as **"unknown"** and **"Unavailable"**.
* Identified employees with **zero salary** requiring validation.
* Converted date columns to proper datetime format.
* Checked for duplicate records and validated data quality.
* Performed Exploratory Data Analysis (EDA).
* Created visualizations using Matplotlib.
* Generated department-wise and salary-based insights.

## Business Insights

### Employee Distribution by Department

* HR: **3 employees**
* IT: **2 employees**
* Sales: **2 employees**
* Finance: **2 employees**

**Insight:** HR has the highest employee count, while IT, Sales, and Finance have equal representation.

### Gender Distribution

* Male: **4 employees**
* Female: **5 employees**

**Insight:** The workforce has a nearly balanced gender distribution with a slightly higher number of female employees.

### Salary Analysis

* Highest Salary: **₹60,000 (IT Department)**
* Lowest Valid Salary: **₹45,000 (HR Department)**
* Zero Salary Records: **1 employee (Finance)** – requires data validation.
* Total Salary (excluding zero salary): **₹4,09,000**
* Average Salary (excluding zero salary): **₹51,125**

**Insight:** IT department has the highest-paid employee, while one salary record needs correction before payroll reporting.

### Data Quality Findings

* 1 employee name recorded as **"unknown"**.
* 1 email marked as **"Unavailable"**.
* 1 invalid salary value (0).
* 1 inconsistent joining date (future year **2026**) requiring verification.

### Joining Trend

* Most employees joined between **January and August 2024**.
* One record contains an incorrect joining date, indicating the need for data validation before reporting.

## Key Business Outcomes

* Improved employee data quality by identifying missing and invalid records.
* Enhanced dataset reliability for HR reporting and payroll analysis.
* Provided actionable insights into department distribution, salary trends, and workforce composition.
* Prepared a clean dataset for dashboard creation and future analytics.
